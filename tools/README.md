# 历史开发与验证工具

此目录用于保留 Minecraft 陪玩开发相关源码，方便后续规划和审计。`local-validation/` 包含保存世界检查、旧阶段审计和夹具导出等工具；`legacy-controlled/` 是旧受控服务器实验。

这里的工具有的会启动客户端、修改开发副本或依赖特定本地保存世界。上传过程没有执行它们。它们不属于当前正式代理验收链，不应直接运行全部脚本，也不能把旧独立客户端的交互结果用于通过当前整体验收。

正式入口与最新状态见仓库根 README.md 和 STATUS.md。历史证明文件中的 SHA-256 标识原始开发文件；路径改为相对路径后，其字节一致性测试会保留失败，不能重写旧证明去伪装继承原来的通过结果。
